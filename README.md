# DelyPasteries React App

DelyPasteries is a bakery landing page built with React. It showcases freshly baked products, contact details, and social links in a responsive layout.

## Features

- Responsive product grid that adapts to screen size.
- Product images, names, and descriptions.
- Bakery-themed colors and interactive hover effects.
- Footer with contact details and social media links.

## Available Scripts

Run these commands in the project directory:

### `npm start`

Starts the development server at [http://localhost:3000](http://localhost:3000).

### `npm test`

Runs the test suite.

### `npm run build`

Builds the production app into the `build` folder.

## Project Structure

- `src/App.css` - Responsive styles for the landing page.
- `src/DelyPasteries.jsx` - Main landing page component.
- `public/image/` - Product and social media images.
